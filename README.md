# NEON//CORE — Cyborg-Themed Landing Page

A responsive sci-fi/cybernetic landing page concept built with HTML, CSS, and vanilla JavaScript.

## Features
- Futuristic dark UI with cyan/purple accents, grid overlays, HUD-style chips, and animated details
- Responsive desktop, tablet, and mobile layouts
- Mobile navigation menu
- System metrics dashboard and four augmentation feature cards
- Reduced-motion accessibility support
- No framework or package installation required

## Run locally
Open `index.html` in a modern browser. Internet is needed for the Google Fonts and remote hero image; the layout and text work without them.

## Before submitting
1. Replace the placeholder `hello@example.com` mail link in `index.html` with a real contact or remove the CTA.
2. Check the remote hero image license/availability; replace it with your own image if needed.
3. Test at desktop and mobile widths.
4. Push the complete folder to a public GitHub repository (or ensure the evaluator has access).
5. Record a short walkthrough and upload it to Google Drive with General access set to Anyone with the link — Viewer, if permitted by your account/institution.

## Suggested demo
Show the hero, click the navigation links, scroll through the system dashboard and feature cards, demonstrate the mobile menu using responsive device mode, then show the final call-to-action.
